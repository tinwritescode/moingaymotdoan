# Triển khai lên Vercel

1. Vào vercel.com, chọn Import Project, chọn repo `kinh-thanh` trên GitHub.
2. Giữ mặc định: `vercel.json` đã đặt lệnh build (`pnpm build`) và thư mục xuất (`dist/client`). Không cần biến môi trường.
3. Gói miễn phí (Hobby) là đủ.

Nên làm sau issue 0002, vì trước đó trang công bố chỉ có mục lục trống.
